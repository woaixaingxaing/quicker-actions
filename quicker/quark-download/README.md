# 夸克下载

剪贴板里出现夸克网盘分享链接时，自动用已登录的 Chrome 打开分享页并点击「下载」。结构与「网盘下载」一致，复用同一个公共子程序。

## 流程

```text
剪贴板变化
  → 读取剪贴板文本
  → 正则提取 https?://(?:pan|drive)\.quark\.cn/s/[...]
  → 为空？提示并结束
  → 非空 → 调用子程序「网页打开并点击」
         url = 提取的链接
         locator = role，role = button，value = 下载
         waitMs = 4000，timeoutMs = 10000
  → 成功提示 / 失败提示
```

## 变量

| 变量 | 类型 | 说明 |
| --- | --- | --- |
| `clip` | text | 剪贴板原文 |
| `shareUrl` | text | 正则提取出的分享链接 |
| `okClick` | boolean | 子程序返回的点击结果 |

## 触发器

- 类型：事件触发 → 剪贴板内容改变 `ClipboardChanged`
- 内容类型：`TEXT`
- 文本匹配：`(pan|drive)\.quark\.cn/s/`
- 忽略 Quicker 获取选中文本引起的剪贴板变化：是

## 依赖

- 「Quicker 连接器」浏览器扩展，且 Chrome 中已登录夸克账号
- 夸克网盘客户端
