# 网盘下载

剪贴板里出现百度网盘分享链接时，在**后台标签页**打开分享页并自动点击「下载」，由百度网盘客户端接管任务。

## 流程

```text
剪贴板变化
  → 读取剪贴板文本
  → 正则提取 https?://pan\.baidu\.com/s/[...]
  → 为空？提示并结束
  → 非空 → 调用公共子程序「网页打开并点击」
           （url=分享链接，locator=text，value=下载，
             active=false 后台标签页，autoFallback=true，
             waitMs=1500，timeoutMs=8000）
         → 子程序内部：打开页面 → 文本精确 → 按钮角色 → 链接角色 → 模糊文本
  → 成功写日志；失败时按 tabId 区分「页面没打开 / 找不到下载按钮」
```

## 变量

| 变量 | 类型 | 说明 |
| --- | --- | --- |
| `clip` | text | 剪贴板原文 |
| `shareUrl` | text | 正则提取出的分享链接 |
| `okClick` | boolean | 子程序返回的点击结果 |
| `tabId` | integer | 子程序操作的标签页 ID（0 = 没打开页面） |
| `matchedBy` | text | 命中的定位方式，仅用于日志 |

## 触发器

- 类型：事件触发 → 剪贴板内容改变 `ClipboardChanged`
- 内容类型：`TEXT`
- 文本匹配：`.*pan\.baidu\.com/s/.*`
- 忽略 Quicker 获取选中文本引起的剪贴板变化：是
- 节流阀：0（触发不稳定时先关掉节流排查）

> 匹配表达式写成 `.*...\.*` 而不是裸的 `pan\.baidu\.com/s/`：真实剪贴板常是「链接: … 提取码: …」整段文本，按整串匹配时裸表达式不中。

## 关键实现说明

### 定位交给公共子程序

不再写死 `button.bottom_download_btn`。分享页改版或按钮换成 `div`/`a` 时，写死的 CSS 会直接失效，而子程序的回退链（文本 → 按钮角色 → 链接角色 → 模糊文本）能兜住大部分情况，还不需要维护选择器。

### 后台标签页

`active: false` 打开，Chrome 不会切标签页、不抢焦点。2026-11-04 实测 3.1 秒完成点击。

注意：后台标签页下**文本精确定位容易失败**（`No descriptor locator resolved to an actionable element`），实际命中的是 `role=button`。这就是 `autoFallback: true` 的原因。

### 提取码页面

带 `?pwd=xxxx` 的链接通常会自动提取，但页面可能先短暂显示「提取文件」输入页。`OpenUrl` 用 `waitComplete: true`，再由 `waitMs` 和定位超时兜住这段等待。

如果链接本身不带提取码，页面会停在输入页，动作无法自动完成，需要手动输入。

## 依赖

- 「Quicker 连接器」浏览器扩展，且 Chrome 中已登录百度网盘账号
- 百度网盘客户端（网页点击下载后由客户端接管）
- 公共子程序「网页打开并点击」（`%%f89423ad-7e45-4105-b5be-935167a18570`）

## 实测

- 2026-11-01：11.15 GB 文件夹，SVIP 加速，客户端接管成功。
- 2026-11-02：旧链路（写死 `button.bottom_download_btn`）修复后定位成功。
- 2026-11-04：改为调用公共子程序 + 后台标签页；日志 `网页打开并点击：下载 → role:button（tab 1305194601）`，3.1 秒完成，未抢焦点。

## 注意

- 客户端已运行时，网页点「下载」直接建任务；客户端未运行时，只会唤起客户端并打开「资源分享」页，需要在客户端里再点一次「下载」。
- `PageAction` 可能输出 `LOW_CONFIDENCE` 警告；只要 `isSuccess=true` 即表示操作已执行。
- 后台标签页会留在标签栏里；不想留可以让动作点完后关闭该 `tabId`。
