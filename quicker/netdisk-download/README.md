# 网盘下载

剪贴板里出现百度网盘分享链接时，自动用已登录的 Chrome 打开分享页并点击「下载」，由百度网盘客户端接管任务。

## 流程

```text
剪贴板变化
  → 读取剪贴板文本
  → 正则提取 https?://pan\.baidu\.com/s/[...]
  → 为空？提示并结束
  → 非空 → 调用子程序「网页打开并点击」
         url = 提取的链接
         locator = role，role = button，value = 下载
         pageUrlPattern = https://pan.baidu.com/s/*
         waitMs = 4000，timeoutMs = 10000
  → 成功提示 / 失败提示
```

## 变量

| 变量 | 类型 | 说明 |
| --- | --- | --- |
| `clip` | text | 剪贴板原文 |
| `shareUrl` | text | 正则提取出的分享链接 |
| `okClick` | boolean | 子程序返回的点击结果 |

## 触发器

- 类型：事件触发 → 剪贴板内容改变 `ClipboardChanged`
- 内容类型：`TEXT`
- 文本匹配：`pan\.baidu\.com/s/`
- 忽略 Quicker 获取选中文本引起的剪贴板变化：是

## 依赖

- 「Quicker 连接器」浏览器扩展，且 Chrome 中已登录百度网盘账号
- 百度网盘客户端（网页点击下载后由客户端接管）

## 实测

2026-11-01 全流程通过：剪贴板事件触发 → Chrome 打开分享页 → 点击下载 → 客户端传输列表出现任务（11.15 GB 文件夹，SVIP 加速）。

已在客户端运行时，点击网页「下载」直接建任务；客户端未运行时，只会唤起客户端并打开「资源分享」页，需要在客户端里再点一次「下载」。

## 注意

点击按钮时 Quicker 扩展可能报 `LOW_CONFIDENCE`（页面存在多个「下载」按钮）。实测两个按钮行为一致，不影响结果；如需更严格的定位，可把 `locator` 改成 `css` 并提供具体选择器。
