# Quicker 触发器配置

两个动作建好并**保留到动作库**之后，再挂下面三条触发器。

## 1. 锁屏 → 关闭插座

- 触发器类型：事件触发
- 事件：计算机锁定（`SessionLock`）
- 动作：米家插座 关闭
- 备注：锁屏关闭米家插座3

## 2. 解锁 → 打开插座

- 触发器类型：事件触发
- 事件：计算机解锁（`SessionUnlock`）
- 动作：米家插座 开启
- 备注：解锁恢复米家插座3供电

## 3. 双击右 Ctrl → 打开插座

- 触发器类型：按键双击
- 按键：右 Ctrl（VK 163）
- 动作：米家插座 开启
- 备注：右Ctrl双击开启米家插座3

## 注意

1. 动作必须先离开「暂存区」。还在暂存区的动作，触发器调不起来，表现为按了没反应。
2. 键盘触发器只在已解锁的桌面有效。锁屏界面属于 Windows 安全桌面，按键不会传给 Quicker。
3. 如果同时装了其他键盘工具，确认它没有抢占右 Ctrl。
4. 想临时停用整套自动化，把这三条触发器禁用即可，不用改脚本。

## 动作参数

两个动作都是「运行或打开」：

```json
{
  "payloadType": "Basic.RunOrOpen",
  "fileName": "C:\\Users\\<用户名>\\AppData\\Local\\Programs\\Python\\Python312\\python.exe",
  "arguments": "\"C:\\path\\to\\plug.py\" on",
  "runAsAdmin": false,
  "waitForExit": false,
  "windowStyle": "1",
  "setWorkingDir": true,
  "workingDir": "C:\\path\\to",
  "activateWindowIfRunning": false
}
```

关闭动作只把 `arguments` 里的 `on` 换成 `off`。
