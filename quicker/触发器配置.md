# Quicker 触发器配置

所有动作都要先**保留到动作库**（离开「暂存区」），再挂触发器。还在暂存区的动作，触发器调不起来，日志里会报「未能找到动作」。

## 一、网盘下载

- 触发器类型：事件触发
- 事件：剪贴板内容改变（`ClipboardChanged`）
- 动作：网盘下载
- 参数：内容类型 `TEXT`；文本匹配表达式 `pan\.baidu\.com/s/`；忽略 Quicker 获取选中文本引起的剪贴板变化
- 备注：百度网盘分享链接：打开分享页并自动点击下载

## 二、夸克下载

- 触发器类型：事件触发
- 事件：剪贴板内容改变（`ClipboardChanged`）
- 动作：夸克下载
- 参数：内容类型 `TEXT`；文本匹配表达式 `(pan|drive)\.quark\.cn/s/`；忽略 Quicker 获取选中文本引起的剪贴板变化
- 备注：夸克网盘分享链接：打开分享页并自动点击下载

## 三、锁屏 → 关闭插座

- 触发器类型：事件触发
- 事件：计算机锁定（`SessionLock`）
- 动作：米家插座 关闭
- 备注：锁屏关闭米家插座3

## 四、解锁 → 打开插座

- 触发器类型：事件触发
- 事件：计算机解锁（`SessionUnlock`）
- 动作：米家插座 开启
- 备注：解锁恢复米家插座3供电

## 五、双击右 Ctrl → 打开插座

- 触发器类型：按键双击
- 按键：右 Ctrl（VK 163）
- 动作：米家插座 开启
- 备注：右Ctrl双击开启米家插座3

## 注意

1. 动作必须先离开「暂存区」。这是「触发器没反应」最常见的原因。
2. Quicker 免费版限制 2 条自定义事件触发。目前「网盘下载」和「夸克下载」两条剪贴板规则已用满配额，再加新的事件规则会被拒绝。
3. 键盘触发器只在已解锁的桌面有效；锁屏界面属于 Windows 安全桌面，按键不会传给 Quicker。
4. 想临时停用某套自动化，禁用对应触发器即可，不用改脚本。

## 米家插座动作参数

两个动作都是「运行或打开」：

```json
{
  "payloadType": "Basic.RunOrOpen",
  "fileName": "C:\\Users\\<用户名>\\AppData\\Local\\Programs\\Python\\Python312\\python.exe",
  "arguments": "\"C:\\path\\to\\plug.py\" on",
  "runAsAdmin": false,
  "waitForExit": false,
  "windowStyle": "1",
  "setWorkingDir": true,
  "workingDir": "C:\\path\\to",
  "activateWindowIfRunning": false
}
```

关闭动作只把 `arguments` 里的 `on` 换成 `off`。
